# Experiment 10: Paging Technique

## Ex. No: 10

### Aim
To implement the Paging Technique and perform logical-to-physical address translation in memory management.

---

### Concepts Used

1. **Page**: A fixed-size block of logical memory space.
2. **Frame**: A fixed-size block of physical RAM memory space.
3. **Page Table**: Data structure storing the mapping between logical pages and physical frames.
4. **Logical Address**: Address generated by the CPU during instruction execution.
5. **Physical Address**: Actual location address in main memory (RAM).

---

### Formulas Used

$$\text{Page Number} = \left\lfloor \frac{\text{Logical Address}}{\text{Page Size}} \right\rfloor$$

$$\text{Offset} = \text{Logical Address} \pmod{\text{Page Size}}$$

$$\text{Physical Address} = (\text{Frame Number} \times \text{Page Size}) + \text{Offset}$$

---

### Algorithm

1. Read the page size (`pageSize`).
2. Read the total number of pages (`numPages`).
3. Read the page table entries (frame numbers corresponding to each page).
4. Read the logical address to be translated (`logicalAddress`).
5. Calculate Page Number: `pageNumber = logicalAddress / pageSize`.
6. Calculate Offset: `offset = logicalAddress % pageSize`.
7. Check if `pageNumber >= numPages`. If so, print "Invalid Logical Address" and stop.
8. Look up Frame Number from Page Table: `frameNumber = pageTable[pageNumber]`.
9. Calculate Physical Address: `physicalAddress = (frameNumber * pageSize) + offset`.
10. Display Page Number, Offset, Frame Number, and Physical Address.
11. Stop.

---

### C Program

```c
#include <stdio.h>

int main()
{
    int pageTable[20];
    int pageSize;
    int numPages;
    int logicalAddress;
    int pageNumber;
    int offset;
    int frameNumber;
    int physicalAddress;
    int i;

    printf("Enter Page Size: ");
    scanf("%d", &pageSize);

    printf("Enter Number of Pages: ");
    scanf("%d", &numPages);

    printf("Enter Frame Numbers for Each Page:\n");
    for(i = 0; i < numPages; i++)
    {
        printf("Page %d -> Frame: ", i);
        scanf("%d", &pageTable[i]);
    }

    printf("Enter Logical Address: ");
    scanf("%d", &logicalAddress);

    pageNumber = logicalAddress / pageSize;
    offset = logicalAddress % pageSize;

    if(pageNumber >= numPages)
    {
        printf("Invalid Logical Address\n");
        return 0;
    }

    frameNumber = pageTable[pageNumber];
    physicalAddress = (frameNumber * pageSize) + offset;

    printf("\nPage Number      : %d", pageNumber);
    printf("\nOffset           : %d", offset);
    printf("\nFrame Number     : %d", frameNumber);
    printf("\nPhysical Address : %d\n", physicalAddress);

    return 0;
}
```

---

### Shell Program (`paging.sh`)

```bash
#!/bin/bash
echo "Enter Page Size:"
read pageSize

echo "Enter Number of Pages:"
read numPages

declare -a pageTable

for ((i=0;i<numPages;i++))
do
    echo "Enter Frame Number for Page $i:"
    read pageTable[$i]
done

echo "Enter Logical Address:"
read logicalAddress

pageNumber=$((logicalAddress / pageSize))
offset=$((logicalAddress % pageSize))

if [ $pageNumber -ge $numPages ]
then
    echo "Invalid Logical Address"
    exit
fi

frameNumber=${pageTable[$pageNumber]}
physicalAddress=$((frameNumber * pageSize + offset))

echo "Page Number      : $pageNumber"
echo "Offset           : $offset"
echo "Frame Number     : $frameNumber"
echo "Physical Address : $physicalAddress"
```
